🌐 Web 管理端

启用 Web 管理界面 (webui.enabled)
仅允许本机访问 (localOnly)

关闭后将绑定 0.0.0.0，允许局域网/远程设备访问管理界面。

禁用 Web 管理界面后将不再启动 HTTP 服务。

添加 Windows 防火墙入站规则，允许局域网设备访问本页面。

🔄 更新与自动备份

更新前自动备份 (updateConfig.autoBackup)

在 WebUI 或命令行更新升级前自动备份当前版本（保留最近 3 个历史备份），便于出现异常时一键回滚。关闭后将跳过备份直接覆盖。

🔗 GitHub API Token

用于减少 GitHub API 速率限制（未认证 60 次/小时，认证后 5000 次/小时）。 在 github.com/settings/tokens 创建，只需 public_repo 读取权限。 ⚠️ 请勿泄露此 Token，不要提交到公开仓库！export 导出时不会包含此 Token。

📦 立即备份

立即对当前 EnderBridge 项目代码、配置与资源完整打包备份，生成全量还原快照。自动遵循备份轮转策略（最多保留 3 份历史备份）。

⏪ 历史备份与恢复

选择历史备份可一键将服务器恢复到该快照版本。恢复前系统会自动为当前状态生成兜底快照，并自动重启上线。
