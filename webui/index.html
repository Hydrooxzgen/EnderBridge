ℹ️ 说明

此页面用于在浏览器中管理 EnderBridge 服务器。
· 权限管理：增删 owner / op / user / blocker 玩家列表
· 功能设置：开关 QQ 桥接、音乐打击乐、限流等,以及 Web 端口与令牌
· Mod 管理：查看客户端/服务端 Mod 加载配置,一键重载服务端 Mod
注意:功能设置的修改需重启服务器后完全生效。
